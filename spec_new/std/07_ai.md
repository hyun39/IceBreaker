## LangChain 체인 패턴

```python
# 패턴: PromptTemplate | LLM | PydanticOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import PydanticOutputParser

parser = PydanticOutputParser(pydantic_object=Summary)

chain = (
    PromptTemplate(
        template="...\n{format_instructions}",
        partial_variables={"format_instructions": parser.get_format_instructions()}
    )
    | ChatOpenAI(model="gpt-3.5-turbo", temperature=0)
    | parser
)

result: Summary = await chain.ainvoke({"information": data})
```

## ReAct 에이전트 패턴

```python
from langchain.agents import create_react_agent, AgentExecutor
from langchain import hub

agent = create_react_agent(
    llm=ChatOpenAI(model="gpt-4o-mini", temperature=0),
    tools=[tavily_search_tool],
    prompt=hub.pull("hwchase17/react"),
)

executor = AgentExecutor(
    agent=agent,
    tools=[tavily_search_tool],
    max_iterations=5,                    # 무한 루프 방지
    handle_parsing_errors=True,          # 파싱 오류 재시도
    verbose=False,                       # 운영: False
)

result = await executor.ainvoke({"input": prompt})
```

## 모델 선택 기준

| 모델 | 용도 |
|------|------|
| `gpt-4o` / `claude-opus` | 복잡한 다단계 추론 |

| `gpt-3.5-turbo` | 포맷 변환 체인 (비용 절감) |

## RAG 핵심 패턴

```python
# Cache-Aside: 벡터 스토어 캐시 조회 → Miss 시 LLM 실행
async def get_analysis(name: str):
    cached = await vectorstore.similarity_search(name, k=1, score_threshold=0.9)
    if cached:
        return cached[0].metadata["result"]

    result = await run_pipeline(name)
    vectorstore.add_documents([Document(
        page_content=name,
        metadata={"result": result, "created_at": now()}
    )])
    return result
```
