# 비즈니스 요건 — Ice Breaker

## 목적

사람 이름을 입력하면 LinkedIn·Twitter 프로필을 자동 분석하여  
**개인화된 대화 시작 문구(Ice Breaker)** 를 생성하는 웹 서비스

---

## 핵심 가치

| 가치 | 설명 |
|------|------|
| 개인화 | 대상자의 실제 관심사·경력 기반으로 생성 |
| 시간 절감 | 수동 프로필 조사 없이 즉시 대화 소재 제공 |
| 신뢰성 | 공개 데이터(LinkedIn, Twitter)만 사용 |

---

## 사용자 시나리오

1. 사용자가 웹 화면에서 상대방 이름을 입력한다
2. 시스템이 LinkedIn 프로필 URL을 자동 탐색한다
3. 시스템이 Twitter 계정을 자동 탐색한다
4. 두 소스의 데이터를 분석해 세 가지 결과를 반환한다:
   - 인물 요약 + 흥미로운 사실 2가지
   - 관심 주제 3가지
   - 창의적 대화 시작 문구 2가지
