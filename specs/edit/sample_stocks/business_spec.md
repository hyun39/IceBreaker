## 배경 및 목적

미국 주식 시장의 흐름을 파악하려는 내부 분석가와 퀀트 담당자들이 현재 S&P 500 주가 데이터를 얻기 위해 매일 수동으로 외부 사이트를 검색하거나 엑셀 파일을 수작업으로 갱신하고 있다.  
이 과정에 담당자 1인당 하루 평균 30분 이상이 소요되며, Sector 단위 집계나 트렌드 해석은 별도 분석 시간이 추가로 필요하다.  
**거래일마다 S&P 500 주가를 자동으로 수집·집계하고 LLM이 Sector 트렌드를 해석하여 한 화면에서 확인할 수 있게 함으로써 분석 준비 시간을 없애고, 의사결정에 집중할 수 있는 환경을 만든다.**

## 사용자 시나리오

### 시나리오 1 — 거래일 마감 후 Sector 흐름 확인 (Happy Path)

**전제 조건**: 사용자가 로그인 상태이며, 당일이 미국 주식 거래일이다. 파이프라인이 정상 완료됐다.

1. 사용자가 서비스에 접속하면 오늘 날짜가 기본 선택된 분석 화면이 열린다.
2. 사용자가 **DW 탭**을 선택하면 11개 Sector의 당일 수익률 비교 차트와 집계 수치가 표시된다.
3. 사용자가 특정 Sector(예: Information Technology)를 클릭하면 해당 Sector 내 상승/하락 종목 수와 상위 등락 종목이 표시된다.
4. 사용자가 **Mart — Key Index 탭**으로 이동하면 RSI, 이동평균, 거래량 이상 여부 등 주요 지표 카드가 Sector별로 표시된다.
5. 사용자가 **Mart — Trend Analysis 탭**으로 이동하면 LLM이 생성한 Sector별 트렌드 요약·주요 동인·리스크·투자 참고 의견이 카드 형태로 표시된다.

**완료 기준**: 사용자가 당일 모든 Sector의 Key Index와 LLM 트렌드 분석을 5분 이내에 확인한다.

---

### 시나리오 2 — 특정 날짜의 ODS 원시 데이터 검증 (퀀트 분석가)

**전제 조건**: 사용자가 특정 날짜의 집계 결과가 의심스러워 원본 데이터를 확인하려 한다.

1. 사용자가 날짜 선택기에서 확인하려는 거래일을 선택한다.
2. 사용자가 **ODS 탭**을 선택하면 해당 날짜의 전체 종목 OHLCV 원본 데이터가 테이블로 표시된다.
3. 사용자가 Sector 필터 또는 ticker 검색으로 특정 종목의 수치를 확인한다.
4. 사용자가 DW 탭으로 이동해 ODS 원본이 집계에 정확히 반영됐는지 비교한다.

**완료 기준**: 사용자가 ODS와 DW 수치를 레이어 이동만으로 비교 확인할 수 있다.

---

### 시나리오 3 — LLM 트렌드 분석 미완료 시 대기 (Exception)

**전제 조건**: 사용자가 접속했으나 당일 LLM Agent 분석이 아직 진행 중이다.

1. 사용자가 **Mart — Trend Analysis 탭**을 선택한다.
2. 시스템이 "분석 진행 중" 안내 배너와 예상 완료 시간을 표시한다.
3. 시스템이 자동으로 완료 여부를 확인하고, 완료되면 화면이 자동 갱신된다.

**완료 기준**: 사용자가 수동 새로고침 없이 분석 완료 결과를 확인할 수 있다.

---

### 시나리오 4 — 비거래일 접속 (Edge Case)

**전제 조건**: 사용자가 미국 공휴일 또는 주말에 접속한다.

1. 사용자가 오늘 날짜로 접속하면 "해당 날짜는 미국 주식 비거래일입니다" 안내가 표시된다.
2. 시스템이 가장 최근 거래일을 자동 선택해 데이터를 표시한다.

**완료 기준**: 사용자가 비거래일에도 최근 거래일 데이터를 혼란 없이 확인할 수 있다.

---

### 시나리오 5 — 과거 날짜 트렌드 비교 (Should Have)

**전제 조건**: 사용자가 특정 Sector의 과거 흐름을 비교하려 한다.

1. 사용자가 날짜 선택기에서 과거 날짜를 선택한다.
2. 시스템이 해당 날짜의 Key Index와 Trend Analysis를 표시한다.
3. 사용자가 Mart Key Index 탭에서 해당 Sector의 최근 60일 추이 차트를 확인한다.

**완료 기준**: 사용자가 과거 임의 거래일의 분석 결과를 오늘 날짜와 동일한 방식으로 조회할 수 있다.

## 기능 요건

### 필수 (Must Have)

- [ ] FR-01: 시스템은 매 거래일 장 마감 후 S&P 500 전 종목의 일별 주가(OHLCV)를 자동으로 수집해 ODS에 적재한다.
- [ ] FR-02: 시스템은 ODS 데이터를 기반으로 11개 GICS Sector별 당일 집계 지표(평균 종가, 수익률, 거래량, 상승/하락 종목 수)를 DW에 생성한다.
- [ ] FR-03: 시스템은 DW 집계 결과를 바탕으로 Sector별 Key Index(MA, RSI, 거래량 이상, Sector 순위)를 Mart에 적재한다.
- [ ] FR-04: 시스템은 매 거래일 Mart Key Index를 LLM Agent에 입력해 Sector별 트렌드 요약·주요 동인·리스크·투자 참고 의견을 생성하고 Mart에 저장한다.
- [ ] FR-05: 사용자는 ODS, DW, Mart(Key Index, Trend Analysis) 레이어 데이터를 단일 화면에서 날짜·Sector 기준으로 조회할 수 있다.
- [ ] FR-06: 사용자는 날짜를 선택해 과거 거래일의 데이터를 레이어별로 조회할 수 있다.
- [ ] FR-07: 시스템은 LLM Trend Analysis 생성 완료 여부를 화면에 표시하고, 완료 시 자동으로 결과를 노출한다.
- [ ] FR-08: 시스템은 비거래일 접속 시 가장 최근 거래일 데이터를 자동으로 표시한다.

### 권장 (Should Have)

- [ ] FR-09: Mart Key Index 화면에서 선택된 Sector의 최근 60일 MA 및 RSI 추이 차트를 제공한다.
- [ ] FR-10: DW 화면에서 11개 Sector를 수익률 기준으로 비교하는 바 차트를 제공한다.
- [ ] FR-11: 수집 또는 파이프라인 실패 시 담당자에게 알림을 전송한다.
- [ ] FR-12: ODS 테이블에서 종목명 또는 ticker로 검색·필터링할 수 있다.

### 선택 (Nice to Have)

- [ ] FR-13: Trend Analysis 카드에서 LLM이 사용한 데이터 기간(input_date_range)과 모델 정보를 확인할 수 있다.
- [ ] FR-14: 특정 Sector의 LLM 트렌드 분석을 수동으로 재실행 요청할 수 있다.
- [ ] FR-15: Sector 트렌드 변화를 주간·월간 단위로 요약한 추가 뷰를 제공한다.

## 범위 외 (Out of Scope)

- **실시간(인트라데이) 주가 조회**: 이번 버전은 일별 장 마감 기준 데이터만 대상. 실시간은 추후 별도 스펙으로 검토.
- **S&P 500 외 종목(나스닥 100, Russell 2000 등)**: v1에서는 S&P 500 구성 종목만 수집.
- **매수/매도 신호 자동화**: LLM 결과는 내부 참고 자료이며 트레이딩 자동화와 연계하지 않는다.
- **외부 뉴스·공시 연계**: v1은 Mart 수치 기반 분석만 수행. 뉴스 RAG 연동은 v2 검토 항목.
- **개인화 알림(종목별 가격 알림 등)**: 이번 버전 대상 외.
- **다국어 UI**: 한국어 단일 지원.
