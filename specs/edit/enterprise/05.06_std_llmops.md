# Enterprise Spec — LLMOps (LLM 수명주기 관리)

> 조직 전체 **AI 플랫폼 수준의 LLM 수명주기 관리 표준**을 정의한다.  
> LLM을 소비하는 모든 팀이 동일한 게이트웨이·거버넌스·비용 분담 체계를 사용한다.

---

## 전사 LLM 아키텍처

```
[제품 팀 서비스 (Agent/RAG)]
        │ (HTTP / SDK)
        ▼
[LLM Gateway — 내부 프록시]
  ├─ 모델 라우팅 (gpt-4o-mini / claude-haiku / 내부 모델)
  ├─ Rate Limiting (팀별, 서비스별)
  ├─ 비용 집계 (팀·프로젝트·모델별 토큰 추적)
  ├─ Prompt Injection 탐지
  ├─ PII 필터링 (입·출력)
  └─ Audit Log (입력·출력·모델·비용 기록)
        │
        ▼
[LLM Provider]
  ├─ OpenAI (gpt-4o, gpt-4o-mini)
  ├─ Anthropic (claude-opus-4, claude-haiku)
  └─ 내부 Self-hosted (Llama 3, Mistral)
```

## LLM Gateway

### 역할

| 기능 | 설명 |
|------|------|
| 멀티모델 라우팅 | 요청별 모델 선택 (비용·품질·지연 기준) |
| Fallback | Primary 모델 장애 시 자동 Secondary 전환 |
| Rate Limiting | 팀별·서비스별 분당 토큰 한도 |
| 비용 Attribution | 팀·프로젝트·서비스 태그 기반 비용 집계 |
| PII 마스킹 | 입력 프롬프트의 이메일·이름·전화번호 탐지·마스킹 |
| Prompt Injection 탐지 | Jailbreak 패턴 탐지·차단 |
| Audit Log | 모든 LLM 호출의 입력·출력·비용·사용자 기록 |

### 클라이언트 사용법

```python
# 제품 팀 서비스에서 LLM Gateway 호출
from openai import AsyncOpenAI

llm = AsyncOpenAI(
    base_url="https://llm-gateway.internal/v1",   # 내부 게이트웨이
    api_key=settings.llm_gateway_token,            # 팀별 API 토큰
    default_headers={
        "X-Team": "data-platform",
        "X-Service": "sp500-analyzer",
        "X-Project": "sp500-v1",
    },
)

# 일반 OpenAI SDK와 동일한 인터페이스
response = await llm.chat.completions.create(
    model="gpt-4o-mini",   # 게이트웨이가 실제 모델로 라우팅
    messages=[...],
)
```

### Rate Limit 정책

| 팀 등급 | 일별 토큰 한도 | 월 비용 한도 | 초과 시 |
|--------|------------|------------|--------|
| Free (실험) | 100K tokens | $10 | 차단 + Slack 알림 |
| Standard | 1M tokens | $100 | 차단 + 담당자 알림 |
| Pro | 10M tokens | $1,000 | 알림만 |
| Enterprise | 무제한 | 별도 계약 | 알림만 |

## Prompt 거버넌스

### Prompt Registry

모든 프로덕션 프롬프트는 중앙 레지스트리에 등록해 버전·실험·롤백을 관리한다.

```yaml
# prompt-registry/sp500-trend-v1.yaml
id: sp500-sector-trend-analysis
version: "1.2.0"
status: production       # draft | review | production | deprecated
owner: data-platform-team
model_constraints:
  preferred: gpt-4o-mini
  fallback: claude-haiku
  max_tokens: 1500
  temperature: 0

system_prompt: |
  You are a professional equity market analyst...
  [프롬프트 내용]

evaluation:
  dataset: s3://prompts-eval/sp500-trend/
  metrics:
    - faithfulness: ">= 0.85"
    - relevancy: ">= 0.80"
    - sentiment_accuracy: ">= 0.90"

changelog:
  - version: "1.2.0"
    date: 2026-05-01
    change: "이중 언어(KO/EN) 출력 추가"
  - version: "1.1.0"
    date: 2026-04-01
    change: "risk_factors 필드 추가"
```

### Prompt 변경 워크플로

```
개발자: 프롬프트 수정 → PR
        │
        ▼
자동 평가 파이프라인 (CI)
  ├─ ragas Faithfulness ≥ 0.85 ?
  ├─ ragas Relevancy ≥ 0.80 ?
  └─ 회귀 테스트 (golden dataset 100건)
        │
        ▼ 통과 시
AI Engineer 리뷰 + 승인
        │
        ▼
Registry 버전 발행 → 서비스 자동 적용
```

## Evaluation Pipeline

### 평가 지표

| 지표 | 측정 대상 | 목표값 | 도구 |
|------|----------|--------|------|
| Faithfulness | 생성 응답이 컨텍스트에 근거하는지 | ≥ 0.85 | ragas |
| Answer Relevancy | 질문과 답변의 관련성 | ≥ 0.80 | ragas |
| Context Recall | 필요한 정보를 컨텍스트가 포함하는지 | ≥ 0.75 | ragas |
| Sentiment Accuracy | sentiment 분류 정확도 (금융 도메인) | ≥ 0.90 | 자체 |
| Latency | p95 응답시간 | ≤ 5s | OTel |
| Cost per call | 호출당 토큰 비용 | ≤ $0.001 | LLM Gateway |

### 평가 실행 방식

```python
# eval/run_evaluation.py
from ragas import evaluate
from ragas.metrics import faithfulness, answer_relevancy, context_recall

dataset = load_golden_dataset("s3://prompts-eval/sp500-trend/golden.jsonl")

results = evaluate(
    dataset=dataset,
    metrics=[faithfulness, answer_relevancy, context_recall],
    llm=evaluation_llm,           # 평가 전용 LLM (gpt-4o)
    embeddings=evaluation_embed,
)

# CI에서 임계치 미달 시 PR 차단
assert results["faithfulness"] >= 0.85, f"Faithfulness 미달: {results['faithfulness']}"
```

## RAG 엔터프라이즈 패턴

### 전사 공용 Knowledge Base

```
[전사 문서 소스]
  ├─ Confluence (내부 문서)
  ├─ GitHub Wiki (기술 문서)
  ├─ 제품 스펙 (PDF/Markdown)
  └─ 고객 지원 FAQ

        │ (Ingestion Pipeline)
        ▼

[Enterprise Vector Store]
  ├─ Namespace: finance / hr / engineering / product
  ├─ 접근 제어: Keycloak Role 기반
  └─ Weaviate (자체 호스팅) or Pinecone (관리형)
```

### Data Contract (RAG 소비자)

```yaml
# rag-contract/sp500-knowledge.yaml
knowledge_base: finance-public
namespace: market-data
access_role: analyst
chunk_size: 512
overlap: 50
embedding_model: text-embedding-3-small
retrieval:
  strategy: hybrid           # vector + BM25
  top_k: 5
  reranker: cross-encoder
sla:
  freshness: 24h             # 최대 24시간 이내 갱신 보장
  availability: 99.5%
```

## Self-hosted LLM (프라이버시 민감 데이터)

| 기준 | 클라우드 LLM | Self-hosted LLM |
|------|------------|----------------|
| PII 포함 데이터 | 금지 | 필수 |
| 금융 기밀 정보 | 검토 후 사용 | 권장 |
| 일반 분석 | 허용 | 선택 |
| 지연시간 | 낮음 | 높음 (GPU 스케줄링) |
| 비용 | 사용량 기반 | 고정 인프라 비용 |

**Self-hosted 모델 운영**:
- `vLLM` 또는 `Ollama` 기반 Kubernetes Deployment
- GPU: `nvidia.com/gpu: 1` 리소스 요청
- 모델: `Llama-3.1-8B-Instruct`, `Mistral-7B-v0.3`
