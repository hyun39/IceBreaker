# Enterprise Spec — UX 설계: React-only 워크플로우

> **코드가 곧 디자인이다.**  
> Figma 없이 React + Storybook으로 설계·검증·산출물을 완성하는 워크플로우.  
> 공통 기준(`03.01_std_ux_design.md`)을 먼저 읽은 후 이 문서를 적용한다.

---

## 언제 이 워크플로우를 선택하는가

| 조건 | 이유 |
|------|------|
| 전문 디자이너가 팀에 없다 | Figma 라이선스·운영 비용 불필요 |
| 내부 도구·관리자 페이지·대시보드 | 브랜드보다 기능·데이터 표현이 우선 |
| 빠른 반복이 필요한 MVP / POC | 코드 → 스토리 → 리뷰 사이클이 더 빠름 |
| 요건 검증 목적 프로토타입 | `02.02_std_prototype_driven_requirements.md`와 자연스럽게 연결 |
| Design System 신규 컴포넌트 구현 | 코드 → Storybook이 소스 오브 트루스 |

---

## 전체 워크플로우

```
[요건 · 유저스토리]
        │
        ▼  LLM 자동 생성 (02.02 참조)
[L1 React Skeleton]   ← 회색 박스, 레이아웃·흐름만
  Storybook에서 팀 리뷰 (Chromatic PR Preview)
        │  피드백 반영
        ▼
[L2 React Hi-fi]      ← @corp/design-system 컴포넌트, 실 토큰 적용
  Chromatic에서 이해관계자 시각적 승인
        │  승인
        ▼
[L3 Interactive Mockup]  ← MSW + 실제 데이터 모양, 엣지 케이스
  게릴라 테스트 (3~5명)
        │  DoR 통과
        ▼
[프로덕션 코드]       ← L2/L3 컴포넌트 그대로 이식
```

## Design Token 정의 (코드 직접)

Figma 없이 `tokens.ts`에서 토큰을 직접 정의하고 CSS/Tailwind로 내보낸다.

### 파일 구조

```
packages/design-system/
├── src/
│   ├── tokens/
│   │   ├── color.ts        ← 색상 토큰
│   │   ├── typography.ts   ← 타이포 토큰
│   │   ├── spacing.ts      ← 간격 토큰
│   │   ├── motion.ts       ← 모션 토큰
│   │   └── index.ts        ← 전체 export
│   └── components/
├── dist/
│   ├── tokens.css          ← CSS Custom Properties
│   └── tailwind.tokens.js  ← Tailwind extend 설정
└── package.json
```

### 토큰 정의 예시

```typescript
// src/tokens/color.ts
export const colorTokens = {
  // Global tokens (원자값)
  blue: {
    400: '#60A5FA',
    500: '#3B82F6',
    600: '#2563EB',
  },
  // Alias tokens (의미 부여)
  primary:  'var(--color-blue-600)',
  success:  'var(--color-green-600)',
  error:    'var(--color-red-600)',
  warning:  'var(--color-amber-500)',
  neutral:  'var(--color-gray-700)',
  surface:  '#ffffff',
  overlay:  'rgba(0,0,0,0.5)',
} as const;

// 다크 모드 override
export const darkColorTokens = {
  primary: 'var(--color-blue-400)',
  surface: '#111827',
} as const;
```

```typescript
// src/tokens/index.ts → CSS 변수로 내보내기
export function generateCSSTokens(): string {
  return `
    :root {
      --color-primary: ${colorTokens.primary};
      --color-surface: ${colorTokens.surface};
      --spacing-4:     16px;
      --motion-normal: 200ms;
    }
    [data-theme="dark"] {
      --color-primary: ${darkColorTokens.primary};
      --color-surface: ${darkColorTokens.surface};
    }
  `;
}
```

## Storybook — 설계 도구

React-only 워크플로우에서 **Storybook이 Figma를 대체**한다.  
컴포넌트의 "디자인 문서"는 Storybook이고, "시각적 검토 도구"는 Chromatic이다.

### Storybook 스토리 표준

모든 컴포넌트는 **4가지 상태 스토리**를 필수로 작성한다.

```typescript
// components/TrendAnalysisCard/TrendAnalysisCard.stories.tsx
import type { Meta, StoryObj } from '@storybook/react';
import { TrendAnalysisCard } from './TrendAnalysisCard';

const meta: Meta<typeof TrendAnalysisCard> = {
  title: 'Feature/TrendAnalysisCard',
  component: TrendAnalysisCard,
  parameters: {
    layout: 'padded',
    // MSW 자동 연결 (인터랙티브 스토리용)
    msw: { handlers: require('../../mocks/handlers').handlers },
  },
  // 공통 args — 모든 스토리에 기본 적용
  args: { sector: 'Information Technology', sectorCode: 'IT' },
};
export default meta;

// 4가지 필수 상태
export const Default: StoryObj      = { args: { state: 'success', ...trendFixture } };
export const Loading: StoryObj      = { args: { state: 'loading' } };
export const Empty: StoryObj        = { args: { state: 'empty' } };
export const Error: StoryObj        = { args: { state: 'error', errorMsg: '분석 중 오류가 발생했습니다.' } };

// 비즈니스 시나리오 스토리 (검증용)
export const BullishSentiment: StoryObj = {
  name: '시나리오: bullish 상태',
  args: { state: 'success', sentiment: 'bullish', ...trendFixture },
};
export const PendingAnalysis: StoryObj = {
  name: '시나리오: LLM 분석 중',
  args: { state: 'loading', completedSectors: 7, totalSectors: 11 },
};
export const Disclaimer: StoryObj = {
  name: '시나리오: 면책문구 표시',
  args: { state: 'success', showDisclaimer: true, ...trendFixture },
};
```

### Storybook 구성 (`.storybook/preview.ts`)

```typescript
// .storybook/preview.ts
import { initialize, mswLoader } from 'msw-storybook-addon';
import { handlers } from '../src/mocks/handlers';
import '../src/styles/tokens.css';  // 토큰 자동 주입

initialize();

export const loaders = [mswLoader];

export const parameters = {
  msw: { handlers },
  backgrounds: {
    default: 'light',
    values: [
      { name: 'light', value: 'var(--color-surface)' },
      { name: 'dark',  value: '#111827' },
    ],
  },
  a11y: { config: { rules: [{ id: 'color-contrast', enabled: true }] } },
};

// 전역 다크모드 토글 (Storybook 툴바)
export const globalTypes = {
  theme: {
    name: 'Theme',
    defaultValue: 'light',
    toolbar: {
      icon: 'circlehollow',
      items: ['light', 'dark'],
      dynamicTitle: true,
    },
  },
};
```

## Chromatic — 시각적 리뷰·승인

```
개발자: PR 오픈
        │
        ▼ GitHub Actions
Chromatic 빌드 → PR에 시각적 diff 게시
        │
        ▼ 리뷰어
팀 리뷰 (Chromatic UI에서 댓글 + Accept/Deny)
        │ Accept
        ▼
PR 머지 → 시각적 스냅샷 기준선 갱신
```

```yaml
# .github/workflows/chromatic.yml
- name: Chromatic Visual Review
  uses: chromaui/action@v1
  with:
    projectToken: ${{ secrets.CHROMATIC_PROJECT_TOKEN }}
    workingDir: packages/design-system
    onlyChanged: true          # 변경된 컴포넌트만 검사
    exitZeroOnChanges: false   # 변경 있으면 PR 차단 (리뷰 필요)
```

### 이해관계자 승인 흐름

```
개발자 → Chromatic PR Preview URL → Slack으로 공유
이해관계자 → Chromatic UI에서 클릭 탐색 + 댓글
이해관계자 → "Accept" 클릭 = 시각적 승인
개발자 → PR 머지 가능
```

## 컴포넌트 개발 표준

### 파일 구조

```
src/components/TrendAnalysisCard/
├── TrendAnalysisCard.tsx          ← 구현
├── TrendAnalysisCard.stories.tsx  ← 스토리 (설계 문서)
├── TrendAnalysisCard.test.tsx     ← 단위 테스트
├── TrendAnalysisCard.module.css   ← 스타일 (토큰만 사용)
└── index.ts                       ← export
```

### 컴포넌트 구현 원칙

```typescript
// TrendAnalysisCard.tsx
import { Disclaimer } from '@corp/design-system';

interface TrendAnalysisCardProps {
  sector: string;
  sentiment: 'bullish' | 'bearish' | 'neutral';
  state: 'idle' | 'loading' | 'success' | 'error' | 'empty';
  trendSummaryKo?: string;
  trendSummaryEn?: string;
  showDisclaimer?: boolean;
}

export function TrendAnalysisCard({
  sentiment,
  state,
  trendSummaryKo,
  showDisclaimer = true,
}: TrendAnalysisCardProps) {
  const sentimentClass = {
    bullish: 'text-success-600 bg-success-50',
    bearish: 'text-error-600 bg-error-50',
    neutral: 'text-neutral-600 bg-neutral-100',
  }[sentiment];

  if (state === 'loading') return <TrendSkeleton />;
  if (state === 'error')   return <TrendError />;
  if (state === 'empty')   return <TrendEmpty />;

  return (
    <div className="rounded-lg border p-4 space-y-3">
      <span className={`badge ${sentimentClass}`}>{sentiment}</span>
      <p className="text-body">{trendSummaryKo}</p>
      {showDisclaimer && <Disclaimer />}
    </div>
  );
}
```
