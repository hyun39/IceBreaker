# Enterprise Spec — GitOps (ArgoCD 기반 선언적 배포)

> **Git을 단일 진실 소스(Single Source of Truth)로 하는 GitOps 배포 모델**을 조직 표준으로 정의한다.  
> 모든 환경 상태는 Git에 선언되고 자동으로 동기화된다.

---

## GitOps 원칙

| 원칙 | 내용 |
|------|------|
| 선언적 | 원하는 상태(desired state)를 YAML로 Git에 선언 |
| 버전 관리 | 모든 인프라 변경은 PR을 통해 리뷰·머지 |
| 자동 동기화 | Git 상태와 클러스터 상태를 자동으로 일치시킴 |
| 지속적 조정 | 수동 변경(`kubectl apply`)이 감지되면 Git 상태로 복원 |

## ArgoCD 구성

### App of Apps 패턴

```yaml
# apps/dev/root-app.yaml — 모든 dev 앱을 관리하는 루트 Application
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: dev-root
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/org/infra
    targetRevision: main
    path: apps/dev
  destination:
    server: https://kubernetes.default.svc
    namespace: argocd
  syncPolicy:
    automated:
      prune: true       # Git에서 삭제된 리소스 자동 제거
      selfHeal: true    # 수동 변경 자동 복원
```

### 서비스별 Application

```yaml
# apps/prod/sp500-api.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: sp500-api-prod
  namespace: argocd
  annotations:
    notifications.argoproj.io/subscribe.on-sync-failed.slack: platform-alerts
    notifications.argoproj.io/subscribe.on-health-degraded.slack: platform-alerts
spec:
  project: finance
  source:
    repoURL: https://github.com/org/infra
    targetRevision: main
    path: helm/sp500-api
    helm:
      valueFiles:
        - values.yaml
        - values-prod.yaml
      parameters:
        - name: image.tag
          value: "a1b2c3d"    # CI가 PR로 자동 업데이트
  destination:
    server: https://prod-cluster.internal
    namespace: finance-prod
  syncPolicy:
    automated:
      prune: false      # prod는 수동 Sync (안전)
      selfHeal: true
    syncOptions:
      - CreateNamespace=true
      - ApplyOutOfSyncOnly=true
    retry:
      limit: 5
      backoff:
        duration: 5s
        factor: 2
        maxDuration: 3m
  revisionHistoryLimit: 10
```

## 배포 워크플로

```
[개발자]
  코드 PR → main 머지
        │
[CI Pipeline]
  1. 테스트 + 빌드
  2. Docker image push (tag: git-sha)
  3. 이미지 서명 (Cosign)
  4. infra 저장소에 image tag 업데이트 PR 자동 생성
        │ (image-updater 또는 GitHub Actions)
[infra 저장소 PR]
  values-dev.yaml: image.tag → new-sha
        │ PR 자동 머지 (dev) 또는 리뷰 후 머지 (staging/prod)
[ArgoCD]
  Git 변경 감지 → 자동 Sync → K8s 반영
        │
[배포 완료]
  ArgoCD Sync Status: Synced + Healthy
  Slack #deployments 알림
```

### 이미지 태그 자동 업데이트 (ArgoCD Image Updater)

```yaml
# apps/dev/sp500-api.yaml에 어노테이션 추가
metadata:
  annotations:
    argocd-image-updater.argoproj.io/image-list: |
      api=ghcr.io/org/sp500-api
    argocd-image-updater.argoproj.io/api.update-strategy: digest
    argocd-image-updater.argoproj.io/write-back-method: git
    argocd-image-updater.argoproj.io/git-branch: main
```

## 환경별 프로모션 전략

| 환경 | Sync 방식 | 승인 | 이미지 업데이트 |
|------|----------|------|----------------|
| dev | 자동 (Auto Sync) | 불필요 | Image Updater 자동 |
| staging | 수동 Sync (ArgoCD UI/CLI) | 1인 PR 승인 | image tag PR 머지 |
| prod | 수동 Sync (ArgoCD UI/CLI) | 2인 PR 승인 | image tag PR 머지 |

### Canary 배포 (Argo Rollouts 연동)

```yaml
# helm/sp500-api/templates/rollout.yaml
apiVersion: argoproj.io/v1alpha1
kind: Rollout
metadata:
  name: sp500-api
spec:
  replicas: 4
  strategy:
    canary:
      canaryService: sp500-api-canary
      stableService: sp500-api-stable
      steps:
        - setWeight: 10      # 10% 트래픽 → 신버전
        - pause: { duration: 5m }
        - analysis:
            templates:
              - templateName: success-rate
        - setWeight: 50
        - pause: { duration: 10m }
        - setWeight: 100
      analysis:
        successCondition: "result[0] >= 0.99"  # 성공률 99% 이상
```

## ArgoCD RBAC

```yaml
# argocd-rbac-cm.yaml
policy.csv: |
  # finance 팀은 finance 프로젝트만 접근 가능
  p, role:finance-team, applications, get, finance/*, allow
  p, role:finance-team, applications, sync, finance/dev*, allow
  p, role:finance-team, applications, sync, finance/staging*, allow

  # SRE만 prod Sync 허용
  p, role:sre, applications, *, */*, allow
  p, role:sre, clusters, *, *, allow

  g, data-platform-team, role:finance-team
  g, sre-team, role:sre

policy.default: role:readonly
```

## Drift 감지 및 복구

```
[ArgoCD Sync Status]
  Synced + Healthy  → 정상
  OutOfSync        → Git과 클러스터 상태 불일치 (수동 변경 등)
  Degraded         → Pod 비정상 → Slack 알림

[대응]
  dev/staging: Auto selfHeal → Git 상태로 자동 복원
  prod: Slack 알림 → SRE가 원인 확인 후 수동 Sync
```
