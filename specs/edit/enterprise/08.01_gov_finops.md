# Enterprise Spec — FinOps (클라우드 비용 거버넌스)

> 클라우드 비용을 **Engineering Team과 Finance의 공동 책임**으로 만들어  
> 불필요한 지출을 줄이고, 비용을 가치에 연결한다.

---

## FinOps 성숙도 모델

| 단계 | 특징 | 현재 목표 |
|------|------|----------|
| Crawl | 기본 비용 가시화, 태그 시작 | ✅ 즉시 적용 |
| Walk | 팀별 Showback, 최적화 시작 | 3개월 내 |
| Run | 자동 최적화, Chargeback, KPI 연동 | 6~12개월 |

## 비용 가시화 (Cost Visibility)

### 태그(Tagging) 정책

모든 클라우드 리소스에 표준 태그를 필수 적용한다.

| 태그 키 | 값 예시 | 목적 |
|--------|--------|------|
| `team` | `data-platform` | 팀별 비용 집계 |
| `service` | `sp500-api` | 서비스별 비용 집계 |
| `environment` | `prod` / `staging` / `dev` | 환경별 비용 분리 |
| `project` | `sp500-v1` | 프로젝트별 집계 |
| `cost-center` | `CC-1234` | 회계 코드 연동 |

**자동 태그 적용** (Kyverno 정책):

```yaml
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: require-resource-tags
spec:
  validationFailureAction: Enforce
  rules:
    - name: check-required-labels
      match:
        resources:
          kinds: [Deployment, StatefulSet, CronJob]
      validate:
        message: "team, service, environment 레이블이 필요합니다."
        pattern:
          metadata:
            labels:
              team: "?*"
              service: "?*"
              environment: "?*"
```

## Showback / Chargeback

### Showback (팀에 비용 보여주기)

```
[매월 1일 자동 리포트]
  ├─ 팀별 지난달 클라우드 비용
  ├─ 전월 대비 증감율
  ├─ 서비스별 Top 5 비용 항목
  ├─ 예산 대비 실제 사용율
  └─ AI/LLM API 비용 별도 집계

리포트 채널: Slack #finops-{team-name}
리포트 주기: 주간 요약 + 월간 상세
```

### 비용 대시보드 (OpenCost / Kubecost)

```
K8s 네임스페이스별 비용
  └─ finance-prod
       ├─ sp500-api: $45/월
       ├─ sp500-frontend: $8/월
       ├─ postgres: $120/월
       └─ redis: $15/월

AI/LLM 비용 (LLM Gateway)
  └─ data-platform 팀
       ├─ gpt-4o-mini: $3.50/월
       └─ claude-haiku: $1.20/월
```

## 비용 최적화 표준

### 컴퓨팅 최적화

| 항목 | 기준 | 자동화 |
|------|------|--------|
| 미사용 리소스 | CPU 사용률 < 5%, 7일 이상 | 자동 알림 + 7일 후 삭제 |
| Over-provisioned Pod | CPU Request가 실제의 300% 이상 | VPA 권장값 적용 |
| Dev 환경 야간 종료 | 17:00 이후 비업무시간 dev Deployment 0으로 축소 | CronJob (KEDA) |
| Spot Instance 활용 | Non-critical 워크로드 | K8s Node Selector |

**Dev 환경 야간 종료 (KEDA ScaledObject)**:

```yaml
apiVersion: keda.sh/v1alpha1
kind: ScaledObject
metadata:
  name: dev-scale-down-night
spec:
  scaleTargetRef:
    name: sp500-api
  triggers:
    - type: cron
      metadata:
        timezone: Asia/Seoul
        start: "0 17 * * 1-5"   # 평일 17:00 → 0으로 축소
        end: "0 9 * * 1-5"      # 평일 09:00 → 복원
        desiredReplicas: "0"
```

### 데이터 스토리지 최적화

| 항목 | 기준 | 조치 |
|------|------|------|
| DB Cold 데이터 | 90일 이상 미조회 Parquet 파일 | Glacier/Cold 스토리지 이동 |
| 로그 보존 | OpenSearch 90일 → Snapshot → S3 | ILM 정책 |
| DB 스냅샷 | 7일 이상 스냅샷 자동 삭제 | 정책 적용 |

## 예산 관리

### 팀별 월 예산 구조

```
전사 클라우드 예산
  ├─ Platform Engineering 팀: $5,000/월
  │   ├─ K8s 클러스터: $3,000
  │   ├─ 공용 DB: $1,500
  │   └─ CI/CD: $500
  │
  ├─ Data Platform 팀: $2,000/월
  │   ├─ 연산: $800
  │   ├─ 스토리지: $700
  │   └─ LLM API: $500
  │
  └─ [팀별 할당 계속]
```

### 비용 알림 임계치

| 임계치 | 조치 |
|--------|------|
| 예산 70% 달성 | Slack 알림 |
| 예산 90% 달성 | 팀장 이메일 + Slack |
| 예산 100% 달성 | CFO 보고 + 추가 승인 프로세스 |
| 전일 대비 50% 급증 | 즉시 알림 (이상 감지) |

**AWS / GCP Budget Alert 연동**:

```yaml
# Terraform — 비용 알림 설정
resource "aws_budgets_budget" "data_platform" {
  name         = "data-platform-monthly"
  budget_type  = "COST"
  limit_amount = "2000"
  limit_unit   = "USD"
  time_unit    = "MONTHLY"

  notification {
    comparison_operator = "GREATER_THAN"
    threshold           = 90
    threshold_type      = "PERCENTAGE"
    notification_type   = "ACTUAL"
    subscriber_sns_topic_arns = [aws_sns_topic.finops_alerts.arn]
  }
}
```

## LLM 비용 거버넌스

LLM API 비용은 전통적 인프라와 달리 사용량이 급증할 수 있어 별도 관리한다.

| 항목 | 기준 |
|------|------|
| 팀별 일일 토큰 한도 | LLM Gateway에서 강제 (→ `llmops.md`) |
| 월 비용 한도 초과 시 | 자동 차단 + Slack + 예산 증액 요청 |
| 모델별 비용 비교 리포트 | 주간 자동 발행 |
| 비용 대비 품질 분석 | gpt-4o-mini vs gpt-4o 성능 회귀 추적 |

## FinOps KPI

| KPI | 목표 | 측정 주기 |
|-----|------|---------|
| 클라우드 비용 월간 증가율 | < 서비스 성장률 | 월간 |
| 리소스 활용률 (CPU) | > 40% | 주간 |
| Dev 환경 야간 비용 절감율 | > 60% 절감 | 월간 |
| 미태그 리소스 비율 | 0% | 일간 |
| LLM API 비용 / 요청 수 | 추세 우하향 | 주간 |
| 예산 대비 실사용 | 90~100% (Underspend도 비효율) | 월간 |
